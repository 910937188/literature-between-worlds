# 文学的跨学科研究

交互汇报网页。主网页、两个研究页、三个章节导读页与原书标注 PDF 位于 dist 目录，可直接用浏览器打开。

使用 Render Static Site：构建命令 `true`，发布目录 `dist`。不创建服务器、数据库或付费附加服务。

网页正文、字体、Three.js 与 GSAP 运行库已内嵌 HTML。图书馆修复照片位于 library-photos 目录，按浏览需要加载。原书扫描页随 book-pages 目录保存，按阅读需要逐页加载；标注 PDF 和正文视频与网页一起打包，离线可用。开场不依赖外部 CDN；正文中的在线视频仍需访问对应平台。

开场采用用户提供的金泽石川县立图书馆照片，经裁切、去除边缘水印与本机超分辨率修复。电脑端单张照片展示，保留自动开场、鼠标景深与受光变化。右上角馆内导览保留馆方1—4层平面图；有照片的区域可选取不同画面，儿童区、阶梯广场与环形回廊只保留位置说明。署名与版权文字位于正文末尾。

教材三个部分各有详细导读，合计28个阅读节点，可逐页对照扫描原文。58页标注 PDF 含70处重点高亮、旁注和书签。《La Perla》对照区继续支持三项索引切换和桌面鼠标景深视差；触屏与减少动态偏好保留稳定展示。
