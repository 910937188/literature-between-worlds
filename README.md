# 文学的跨学科研究

交互汇报网页。三个 HTML 文件位于 dist 目录，可直接用浏览器打开。

使用 Render Static Site：构建命令 `true`，发布目录 `dist`。不创建服务器、数据库或付费附加服务。

网页正文、图片、字体、书籍标注页、3D图书馆开场、Three.js与 GSAP 运行库均已包含在 HTML 中，离线可用。开场不依赖视频或外部 CDN；正文中的在线视频仍需访问对应平台。源文件用于备份、迁移和教学留存。

开场采用原创3D图书馆：自动镜头动画结束后，可使用鼠标环视，并切换全景、书墙、回廊与天光视角。署名与版权文字位于正文末尾。《La Perla》对照区支持三项索引切换和桌面鼠标景深视差；触屏与减少动态偏好保留稳定展示。
